# AnythingMCP Status

Live status page for AnythingMCP Cloud, the MCP gateway and anythingmcp.com:
**https://status.anythingmcp.com**

Checks run every five minutes on GitHub Actions, outside AnythingMCP's own servers,
so the page stays up when they do not. Downtime opens an issue in this repository and
closes it on recovery. Monitored endpoints are listed in [`.upptimerc.yml`](.upptimerc.yml).

Built with [Upptime](https://upptime.js.org) (MIT).
